# Café Crema — Sunlit Roastery & European Bistro (Demo)

Warm, sunlit demo website for **Café Crema**, Andheri East, Mumbai ([@cafecrema__](https://www.instagram.com/cafecrema__/)).

Pure HTML + CSS + JavaScript. No build step. All images sit in the root folder.

## Run
Open `index.html` in any browser.

## Admin & Kitchen portal
Click **Admin & Kitchen ↗** in the header.
- Username: `crema_manager`
- Password: `CremaAndheri@2026`

Live kitchen order cards with status buttons, reservations list, shift revenue and a demo order button.
Promo code for customers: **CREMA10** (10% off).

> Demo only: orders, bookings and login are stored in the browser (localStorage). For real use, connect a backend and server-side login.

## Deploy on GitHub Pages
1. Create a new GitHub repository and upload all files (drag & drop works).
2. Settings → Pages → Deploy from a branch → `main` / root → Save.
3. Your site goes live at `https://<username>.github.io/<repo>/`.
